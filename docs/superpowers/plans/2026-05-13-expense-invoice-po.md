# Invoice + PO Number on Expenses — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two optional free-text fields — `invoiceNumber` and `poNumber` — to expenses, propagate them across every existing capture/audit path (manual entry, AI receipt extraction, receipt approval, activity log, search), and surface them in the two relevant UI screens.

**Architecture:** Six new nullable columns in the shared Postgres DB (2 on `expenses`, 4 on `receipt_inbox_items`). Web owns the migration; middleware mirrors the schema. Web APIs accept/return/search/log. The Gemini extractor in middleware learns to pull invoice/PO numbers from receipts. The Add Expense modal and the receipt review drawer get two new text inputs each. No new endpoints, no new components, no indexes, no permission changes.

**Tech Stack:** Next.js 16 + React 19 + TypeScript on the web side. Node + BullMQ + Gemini on the middleware side. Prisma 7. PostgreSQL. vitest.

**Spec:** `docs/superpowers/specs/2026-05-13-expense-invoice-po-design.md`

```ts
/**
 * Normalize a short free-text field (invoice number, PO number, etc.):
 * - null / undefined / non-string → null
 * - trim surrounding whitespace
 * - empty after trim → null
 * - cap at 128 characters (the DB column width)
 */
export function normalizeShortText(v: unknown): string | null {
  if (typeof v !== 'string') return null;
  const t = v.trim();
  if (t === '') return null;
  return t.length > 128 ? t.slice(0, 128) : t;
}
```

Create `middleware/src/lib/expense-fields.ts`:

```ts
/**
 * Normalize a short free-text field (invoice number, PO number, etc.):
 * - null / undefined / non-string → null
 * - trim surrounding whitespace
 * - empty after trim → null
 * - cap at 128 characters (the DB column width)
 */
export function normalizeShortText(v: unknown): string | null {
  if (typeof v !== 'string') return null;
  const t = v.trim();
  if (t === '') return null;
  return t.length > 128 ? t.slice(0, 128) : t;
}
```
